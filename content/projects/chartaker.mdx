## Overview

I play Starfinder weekly with a local group, and none of the existing character management tools felt right. They were clunky, overwhelming for new players, and not built with Starfinder in mind. So I built CharTaker to be the tool I wished existed: intuitive enough to help onboard new players while still being useful for experienced ones.

CharTaker lets you create, organize, and track characters across campaigns with a clean interface built on React and Vite.

## Tech Stack

- **Framework**: React with Vite
- **Styling**: CSS with HMR support
- **Linting**: ESLint
