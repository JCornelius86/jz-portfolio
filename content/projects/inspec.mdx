## Overview

A friend of mine owns several SportClips locations and was struggling to keep up with compliance records across all of them. Inspections, certifications, task tracking: it was all scattered and manual. I built Inspec to give him a single dashboard to manage it all.

This was also my first vibe coding project, back in February 2025. It helped me get comfortable with React Native and Expo while solving a real problem for someone I know.

## Tech Stack

- **Framework**: React Native with Expo
- **Navigation**: Expo Router
- **Styling**: React Native StyleSheet with theme support
- **Icons**: Expo Vector Icons
- **Maps**: Google Maps integration
